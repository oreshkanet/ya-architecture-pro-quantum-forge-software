# Аналитика покрытия и качества базы знаний

Это руководство описывает систему аналитики для оценки полноты и качества базы знаний RAG-бота.

## Компоненты системы

### 1. QueryLogger - Модуль логирования запросов

Автоматически логирует каждый запрос к боту с полной информацией:

- Текст запроса
- Timestamp
- Наличие и количество найденных чанков
- Длина ответа
- Флаг успешности ответа
- Найденные источники (metadata)
- Время выполнения (retrieve, generate, total)

**Расположение:** `src/bot/core/query_logger.py`

### 2. Golden Questions - Золотой набор вопросов

Стандартизированный набор из 15 вопросов для тестирования:

- 9 вопросов на известные темы (бот должен ответить)
- 6 вопросов на неизвестные темы (бот должен корректно отказаться)

**Расположение:** `knowledge_config/golden_questions.json`

### 3. Test Script - Скрипт автоматического тестирования

Автоматически тестирует бота на золотом наборе вопросов и генерирует отчёт.

**Расположение:** `src/tests/test_golden_questions.py`

### 4. Log Analyzer - Утилита анализа логов

Анализирует накопленные логи запросов и показывает статистику.

**Расположение:** `tests/analyze_logs.py`

## Критерии оценки качества

### Успешный ответ (для известных тем)

Ответ считается успешным, если:

1. Найдены релевантные чанки (chunks_found = true)
2. Длина ответа > 20 символов
3. Ответ не содержит фраз "не знаю", "не нашёл", "нет информации"
4. Средний score чанков выше порога (-2.0)
5. В ответе присутствуют ключевые слова из вопроса

### Корректный отказ (для неизвестных тем)

Отказ считается корректным, если:
1. Чанки не найдены (chunks_found = false) ИЛИ
2. Ответ короткий (<20 символов) ИЛИ
3. Ответ содержит фразу "не знаю" / "нет информации"

## Интерпретация метрик

### Общая точность

- **≥ 80%** — отлично, база знаний хорошо покрывает темы
- **60-79%** — хорошо, но есть области для улучшения
- **< 60%** — требуется доработка базы знаний

### По категориям

**Известные темы:**
- Цель: ≥ 85% правильных ответов
- Если ниже — нужно дополнить базу знаний по этим темам

**Неизвестные темы:**
- Цель: ≥ 80% корректных отказов
- Если ниже — бот может галлюцинировать или давать неточные ответы

## Рекомендации по улучшению

### Если низкая точность по известным темам

1. **Необходимо дополнить базу знаний:**
   - Добавить больше документов по проблемным темам;
   - Улучшить качество существующих документов;
   - Проверить полноту информации.

2. **Требуется улучшить индексацию:**
   - Проверить качество чанкинга;
   - Улучшить метаданные (tags, categories);
   - Настроить параметры поиска (top_k, rerank).

3. **Оптимизировать промпты:**
   - Улучшить инструкции для LLM;
   - Добавить примеры использования;
   - Настроить другие параметры.

### Если низкая точность по неизвестным темам

1. **Улучшить логику определения отсутствия информации:**
   - Настроить пороги релевантности (score thresholds);
   - Добавить явные инструкции LLM о том, когда говорить "не знаю";
   - Использовать confidence scores.

2. **Добавить валидацию ответов:**
   - Проверять релевантность найденных чанков;
   - Использовать reranking для фильтрации слабых результатов;
   - Внедрить CRAG (Corrective RAG) подход.

### Если высокое среднее время ответа

1. **Оптимизировать retrieval:**
   - Использовать кэширование частых запросов;
   - Оптимизировать размер индекса;
   - Использовать более быстрые модели эмбеддингов.

2. **Оптимизировать генерацию:**
   - Использовать более быстрые LLM модели;
   - Уменьшить max_tokens;
   - Использовать streaming для улучшения UX.
